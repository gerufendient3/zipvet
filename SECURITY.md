# Seguridad

ZipVet analiza archivos no confiables. Tomamos en serio los problemas de seguridad.

**Cómo reportar una vulnerabilidad:** usa la pestaña **Security > Report a vulnerability** del repositorio en GitHub. No abras un issue público con detalles de explotación.

**Alcance:** lectura de ZIP maliciosos, lectura o escritura fuera de memoria, ejecución de código del archivo analizado, fugas de credenciales en la interfaz o en el informe.

**Fuera de alcance:** falsos positivos o negativos de las reglas (abre un issue normal) y la seguridad del proyecto que analizas.

**Versiones soportadas:** solo la última versión publicada.
