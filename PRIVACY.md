# Política de privacidad de ZipVet

**Qué procesa:** el ZIP que tú subes y los archivos de texto permitidos que contiene.

**Dónde:** en memoria, durante la sesión de análisis. ZipVet no escribe el contenido en disco ni en una base de datos, y no lo envía a terceros ni a servicios de IA.

**Qué no hace:** no ejecuta tu código, no instala dependencias, no accede a GitHub y no usa cookies de seguimiento. El ajuste `gatherUsageStats` de Streamlit está desactivado.

**Advertencia para la versión publicada:** si usas una demo alojada en un servicio externo, el ZIP viaja hasta ese servidor para ser analizado. Para código confidencial, ejecuta ZipVet en tu equipo siguiendo el README. No subas credenciales reales a ninguna demo pública.

**Datos de ejemplo:** el proyecto de ejemplo es sintético y sus credenciales son ficticias.
